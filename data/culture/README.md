# Cultural context data

This folder is reserved for reviewed cultural-context entries. Do not add a
claim about Sindhudurg, Konkan, Marathi, or Malvani without recording:

- a source or community contributor;
- a region;
- a verification status: `VERIFIED`, `COMMUNITY_PROVIDED`, or `NEEDS_REVIEW`;
- appropriate educational use.

The app labels material that is not `VERIFIED` as a draft. It must not present
unreviewed context as an established cultural fact.
