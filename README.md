# Malvani Learning AI

Exploring whether regional-language AI systems can improve conceptual learning accessibility for students in Sindhudurg.

## Research Goals

- Experiment with AI explanations in Malvani
- Improve conceptual understanding
- Explore prompt engineering approaches
- Document student learning feedback

## Current Stage

Early experimentation and documentation.

## Planned Phases

### Phase 1
- Prompt experimentation
- Translation testing
- Documentation

### Phase 2
- Student testing
- Feedback collection

### Phase 3
- Iterative improvement
- Expanded deployment

## Notes

This repository is being developed as a long-term learning and research project.
